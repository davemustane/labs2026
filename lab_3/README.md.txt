# Лабораторная работа № 3 — Записная книжка

**Тема:** Консольное приложение «Записная книжка»  
**Студент:** Степанов А.Т., группа ИСП11-51 
**Язык реализации:** C# (.NET 10)  
**Формат хранения данных:** JSON

---

## 1. Постановка задачи

Разработать консольное приложение для ведения записной книжки. Программа должна позволять пользователю добавлять, просматривать, искать по ключевому слову и удалять заметки. Все данные сохраняются в файл и загружаются при следующем запуске.

---

## 2. Требования и запуск

### Требования
- .NET 8 (.NET 10) SDK
- ОС: Windows / Linux / macOS

### Инструкция по запуску
```bash
cd src
dotnet run
```

---

## 3. Формат файла данных

Данные хранятся в файле `data/notes.json` в формате JSON-массива объектов. Каждая заметка имеет структуру:

```json
{
  "Id": 1,
  "Title": "Заголовок",
  "Content": "Текст заметки",
  "CreatedAt": "2026-11-21T09:15:00",
  "Tags": ["тег1", "тег2"]
}
```

---

## 4. Используемые коллекции

- **`List<Note>`** — основная коллекция для хранения всех заметок. Выбор обусловлен необходимостью сохранять порядок добавления и поддерживать операции добавления/удаления/перебора.
- **`List<string>`** — внутри каждой заметки для хранения тегов.
- При поиске используется LINQ-метод `Where()` — демонстрация типовой операции фильтрации.

## 6. Обработка ошибок

| Ситуация | Реакция программы |
|---|---|
| Файл `notes.json` отсутствует | Создаётся пустой список заметок |
| Файл повреждён (невалидный JSON) | Выводится сообщение об ошибке, используется пустой список |
| Пустой заголовок при добавлении | Операция отменяется с сообщением |
| Некорректный ID при удалении | Выводится сообщение, заметка не удаляется |
| Неверный пункт меню | Выводится подсказка, программа продолжает работу |
| Ошибка записи в файл | Выводится сообщение, программа не падает |
